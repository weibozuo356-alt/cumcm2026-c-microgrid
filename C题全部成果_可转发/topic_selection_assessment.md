# A/B/C 选题判断：冲国一是否继续选 C

## 结论

建议继续选 C。按当前材料、团队已有数据交付和 72 小时时间约束，C 是三题中“国一竞争力/失败风险”比值最高的选择，但并不意味着题目本身最容易得高奖。它的优势来自可闭环验证、结果模板明确、四问递进自然和现有数据链路已经完整；真正的风险是模型口径和因果性，而不是求解器难度。

| 维度 | A 药材烘干 | B 干扰源定位清除 | C 微网调控 |
|---|---|---|---|
| 核心难点 | 热湿耦合非线性 PDE、移动边界、参数经验式 | 几何定位、路径规划、未知目标数、在线随机模拟器 | 线性优化、预测误差、滚动控制、价格不确定性 |
| 外部依赖 | 数值 PDE 稳定性和网格收敛 | HTTP 模拟器、正式随机案例、20 分钟程序时限 | 官方 Excel 数据与结果模板 |
| 72 小时完成风险 | 中高 | 很高 | 低到中 |
| 可复算证据 | 需要网格/时间步收敛证明 | 正式测试不可完全复现 | 可逐区间核对平衡、SOC、费用 |
| 创新空间 | 高，但过拟合/数值错误风险高 | 高，但现场测试风险最高 | 中高，可用 CVaR、MPC、联合场景稳健扩展 |
| 当前团队基础 | 未见成型仿真链路 | 未见模拟器训练日志 | 数据、预测、场景、模板链路齐全 |

## 为什么 C 更适合当前队伍

1. 四问共用同一物理模型，新增内容主要是信息结构和目标函数变化，论文主线容易统一。
2. LP 可以稳定覆盖全部问题，避免为了创新转入难验证的强化学习或复杂非线性模型。
3. 有全年 365×144 数据，可做严格样本外误差、极端日、分位数和消融对比。
4. 官方模板清楚，能把“模型—代码—结果—论文表格”做成同一证据链。
5. 当前实算已经给出显著且合理的基线改进，并通过硬约束与费用复算。

## 冲国一最需要注意的问题

1. **不要混淆功率和电量。** 所有 kW 数据进入区间平衡前必须乘 1/6。
2. **时间索引不要整体平移。** 原附件与模板文字存在 10 分钟表面差异，按第 t 个位置严格绑定。
3. **效率只能扣一次。** 充放电定义在交流侧，SOC 方程使用 `0.9c-p/0.9`。
4. **Q2—Q4 不得每日重置 SOC。** 论文图和代码都要展示跨日连接。
5. **真实未来只能用于事后评价。** 计划和滚动预测只使用发布时刻前信息；完美未来必须标注 Oracle 下界。
6. **Q3 结算歧义必须显式处理。** 主文写清公式，替代公式给关键日期敏感性，不要混用。
7. **Q4 必须说明电价何时可知。** 真实价格只能结算，不能偷偷进入优化。
8. **CVaR 不一定优于简单稳健模型。** 当前全年结果已经显示安全裕度优于 8 场景 CVaR，论文应诚实做模型选择。
9. **不要为“无同时充放电”轻率上 MILP。** 先用正电价、效率损耗和数值退化项证明 LP 已自然排除；本结果为 0 个区间。
10. **提交前做三方一致性检查。** 论文数字、CSV 和五个 Excel 必须来自同一次运行，Excel 最后全部重算并保存。

## 国一竞争力的写作重点

把创新放在信息结构和证据，而不是模型名：因果预测选择、完整日联合残差轨迹、四时刻闭环而非四次静态优化、两种结算解释、Oracle 信息价值差距、最差 1%/5%/10% 日期表现。摘要应优先报告基线改善、极端日稳定性和全部硬约束通过，不要把 CVaR 或 MPC 本身当作创新结论。
