# 符号表

| 符号/字段 | 单位 | 定义 |
|---|---:|---|
| `d` | 日 | 逻辑运行日 |
| `t` | 区间 | 1—144 的十分钟区间索引 |
| `s` | 场景 | 不确定性场景索引 |
| `r` | 时刻 | 预测更新时间，0、6、12、18 时 |
| `Delta t` | h | 区间长度，1/6 |
| `L_dt` | kW | 小区负荷功率 |
| `G_dt` | kW | 光伏发电功率 |
| `pi_dt` | 元/kWh | 外网电价 |
| `q0_dt` | kWh | 0:00 确定的日前计划购电量 |
| `qf_dt` | kWh | 更新预测后形成的绝对调整购电量，不是增量 |
| `e_dt` | kWh | 实际缺口对应的紧急购电量 |
| `c_dt` | kWh | 交流侧充电量 |
| `p_dt` | kWh | 交流侧放电量 |
| `E_dt` | kWh | 区间末电池储电量 |
| `w_dt` | kWh | 弃光电量 |
| `u_dt` | kWh | 相对原计划的上调购电量 |
| `v_dt` | kWh | 相对原计划的下调购电量 |
| `eta_c` | — | 充电效率，主模型 0.9 |
| `eta_d` | — | 放电效率，主模型 0.9 |
| `Pmax Delta t` | kWh | 单区间充/放电上限，833.333333 |
| `alpha` | — | CVaR 置信水平，默认 0.90 |
| `lambda` | — | CVaR 风险权重，默认 0.20 |
| `zeta` | 元 | CVaR 的 VaR 辅助变量 |
| `xi_s` | 元 | 场景 s 超过 VaR 的非负损失 |

`purchase_final_kwh` 在 Q2/Q4-2 中等于 `q0+e`，在 Q3/Q4-3 中等于 `qf+e`。
